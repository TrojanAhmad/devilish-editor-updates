# Devilish Editor

Official Windows installation packages and release notes for Devilish Editor, a video editing toolkit for Adobe Premiere Pro.

## Download

Open [Releases](https://github.com/TrojanAhmad/devilish-editor-updates/releases/latest) and download the latest `.zxp` package.

1. Save your project and close Adobe Premiere Pro.
2. Install the ZXP using your Adobe extension installer.
3. Reopen Premiere Pro and open Devilish Editor.
4. Activate using your existing monthly or Lifetime license key.

Version 1.0.7 introduces update notifications and verified downloads inside the extension. Existing users need to install that version or a newer version once to receive future update notifications. Installation remains a user action after closing Premiere.

The extension license and downloaded model/library files are kept in user data folders. Never share your license key publicly.

This repository distributes installation packages. Publishing tools, administrator credentials and signing private keys are not included here.
